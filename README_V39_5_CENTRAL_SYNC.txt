V39.5 — Google Sheets Central Sync

หลักการใหม่:
- Google Sheets เป็น Source of Truth เพียงแห่งเดียว
- หน้าเว็บ / Dashboard / Backup ใช้ข้อมูลจาก Spreadsheet เดียวกัน
- เมื่อแก้ข้อมูลใน Sheet เว็บจะดึงข้อมูลล่าสุดอัตโนมัติประมาณทุก 25 วินาทีเมื่อเปิดหน้าเว็บ
- ปุ่ม "ดึงจาก Sheets" ใช้ข้อมูลล่าสุดจาก Sheet โดยตรง ไม่ Safe Merge ข้อมูลเก่าในเครื่องกลับไปทับ Sheet
- ตอนเชื่อมต่อครั้งแรก ถ้า Sheet มีข้อมูล ระบบใช้ Sheet เป็นหลัก; ถ้า Sheet ว่าง ระบบจึงส่งข้อมูลเริ่มต้นจากเครื่องขึ้น Sheet
- การแก้ไขจากเว็บยังบันทึกกลับ Google Sheets ผ่าน scheduleSheetsPush
- JSON เป็นไฟล์ส่งออก/สำรอง/ย้ายข้อมูล ไม่ใช่ฐานข้อมูลอีกชุด
- ตัดการอ้างว่า Google Drive เป็นฐานข้อมูลหลักออกจาก UI
